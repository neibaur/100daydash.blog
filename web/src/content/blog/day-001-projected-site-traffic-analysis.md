This dashboard creates a simple 100-day launch traffic model for
**100daydash.blog**. The target line grows steadily each day, while the actual
projection includes a small weekly pattern and gradual lift as the project gains
momentum.

The raw generated data lives at
`dashboards/day-001-projected-site-traffic-analysis/data/raw/traffic.csv`, and
the chart is exported as a PNG for the blog hero image.
